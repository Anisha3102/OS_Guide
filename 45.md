# Difference between distributed OS and network OS.

| **Feature**          | **Distributed Operating System**                                                           | **Network Operating System**                                                                  |
| -------------------- | ------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| **Definition**       | Manages a group of independent computers and makes them appear as a single unified system. | Allows computers to communicate and share resources over a network, but each runs its own OS. |
| **System View**      | Appears as one single system to users.                                                     | Each system is visible and managed separately.                                                |
| **Resource Sharing** | Resources (CPU, memory, files) are shared transparently across all nodes.                  | Resources are shared explicitly via network services (e.g., file sharing, printing).          |
| **Dependency**       | Strong interdependence — all nodes cooperate and coordinate closely.                       | Loosely connected — each system can operate independently.                                    |
| **Fault Tolerance**  | High — failure of one node doesn’t affect the whole system (if redundancy exists).         | Low — if a server fails, dependent clients lose access.                                       |
| **Examples**         | Amoeba, LOCUS, Google’s Borg, Hadoop YARN.                                                 | Windows Server, Novell NetWare, UNIX network systems.                                         |


## Tip:

A Distributed OS treats multiple machines as one system, while a Network OS connects separate systems that communicate and share resources over a network.
