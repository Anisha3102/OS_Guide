# Difference between user mode and kernel mode.

| **Feature**       | **User Mode**                                                                    | **Kernel Mode**                                                                          |
| ----------------- | -------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| **Definition**    | Mode where application programs run with limited access to system resources.     | Mode where the operating system core (kernel) executes with full access to all hardware. |
| **Access Rights** | Restricted — cannot directly access hardware or kernel memory.                   | Full access to hardware, memory, and system resources.                                   |
| **Purpose**       | To protect the system by isolating user applications from critical OS functions. | To manage and control all system resources and execute privileged instructions.          |
| **System Calls**  | Must use system calls to request kernel services.                                | Executes system calls and handles low-level tasks.                                       |
| **Fault Impact**  | Errors affect only the specific application.                                     | Errors can crash the entire system.                                                      |
| **Example**       | Running apps like Chrome, Word, or Notepad.                                      | Running OS components like process scheduler, memory manager, device drivers.            |
